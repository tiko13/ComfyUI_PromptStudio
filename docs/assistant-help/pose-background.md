In a Qwen Edit or RGBA Edit workflow wired for pose inpainting, open References and select a Pose structure guide. Preserve background is on by default. Edit background mask estimates coverage of the original and target bodies when no matching saved mask exists. Review hair, loose clothing, objects and shadows. Pink areas regenerate; unpainted pixels stay unchanged. Change Mask padding and click Estimate from poses to replace the estimate; Undo restores prior painting. Paint/Erase use a visible brush-size circle; brush size, Undo and Clear mask help refine it. Apply mask saves it; Cancel discards changes.
Review again after changing the pose. A mask from another source is rejected. Preservation requires an applied mask. Estimation needs pose extraction for the original source and editable target joints or a photo. If detection fails or multiple people are ambiguous, paint manually. Whole guide explicitly allows everyone to be included. Placement rectangles are separate from the source-space mask.
The workflow feeds the original image and mask into native Qwen control plus inpainting, then composites using that same mask and saves losslessly. Pixels inside the mask can still change; overly tight masks can clip new limbs or leave the old body visible. Describe the intended pose and retain the scene in your edit request.
Uncheck Preserve background to allow full-scene changes; the saved mask stays available. This does not guarantee removal or transparency. Use a Background Removal workflow for that. Create and workflows without the required node wiring do not show the checkbox. H3 Video workflows do not use this Qwen image-inpainting path.
