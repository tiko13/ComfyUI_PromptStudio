Personal prompt configuration lives in Prompt Studio's Git-ignored config/user/ folder: model_profiles.json, styles.json, framing.json, instructions.json, references.json, protected_words.json, forbidden_words.json. Each file has version 1 and an items array. Protected-word items are strings; other categories use their existing object fields. Use Settings editors or edit these JSON files. Forbidden-word rules are shared with Video; image prompt profiles and presets do not configure Video's structured Director prompts.
Leave config/defaults/*.psc unchanged: these are tracked application resources, including starter examples. The extension discourages accidental editing; it is not encryption. Old root-level user files convert automatically on first use; their exact originals are archived under ignored config/migration-backups/ before removal. Existing new files win; older copies are retained as backups. Invalid files report an error instead of being overwritten. Keep an empty items array to clear a category.
Reload model profiles in Settings after manual edits; refresh the ComfyUI canvas for updated node dropdowns. Mutation settings detect valid file changes while open. LlamaCPP server configurations retain their separate config/LlamaCPP/ schema; histories, workflows and browser preferences are separate runtime state.

Each Studio keeps its server-side histories and workflow caches in its own ignored user-data/ folder. Image plots, model metadata, optional reference models and Llama.cpp process/autostart state also live there. Startup moves older root stores automatically, preserving backups; a destination conflict preserves both copies and reports an error. Browser preferences remain in the browser.
