KoboldCpp Apply (KCPP_Apply) sends text as the complete raw prompt/context to KoboldCpp's /api/v1/generate and returns one STRING named text. Supply your own task and context. It adds no model profile, style, framing or image-amplification instructions. kobold_url, max_response_tokens, sampling settings, sampler_seed, thinking_mode, stop_sequence and request_timeout configure the request. Its token limit is the total raw-generation allowance. This canvas node remains KoboldCpp-specific even if the Studio assistant uses another provider.
Ideogram4-KoboldCPP (KCPP_Ideogram4) takes json_input and returns json_output (STRING). It rewrites high_level_description, compositional_deconstruction.background, and non-text elements' desc fields, selected by process_* switches. It preserves bounding boxes, element types, literal text elements, unknown keys and unselected fields. Each fragment is sent separately; the LLM does not see the surrounding JSON. Use valid object JSON, not plain prose. Prompt profile, style, framing, embellishment, thinking and request controls follow Prompt Amplify. seed_mode controls per-field seed offsets, on_error chooses failure or keeping an original field, and pretty_json changes output formatting.
For a manual multi-stage LLM graph, connect STRING outputs to compatible text inputs and supply clear instructions at each stage. Independent nodes are not ordered by their canvas positions; data links establish dependencies. Neither Apply nor Ideogram4 is the prompt attachment required to register an Image Studio Create/Edit workflow: use a Prompt Slot or Prompt Amplify for that handoff.
