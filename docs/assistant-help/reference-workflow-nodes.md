These declarations configure Image Studio; Video keeps its MiniMax Director contract. Collection -> Item -> model IMAGE input works with native ComfyUI or custom encoders. Collection is PS_REFERENCES data, not IMAGE. Item converts one entry to standard sockets; it is not Qwen-specific.
Prompt Studio Reference Collection (PS_ReferenceCollection) declares minimum/maximum and comma-separated role identifiers. Its PS_REFERENCES output connects to Prompt Studio Reference Item (PS_ReferenceItem); one-based index selects an IMAGE/MASK pair. Wire each advertised slot to the model, or use a compatible custom node consuming PS_REFERENCES directly. Empty optional items return None; downstream nodes must accept absence. Studio supports bounds through 64; the model may support fewer. Minimum counts semantic references; maximum also includes an attached structure guide.
Prompt Studio Reference Prompt Settings (PS_ReferencePrompt) sits between Prompt Slot and the encoder. Connect the collection to its references input. Set edit_instruction or full_prompt, reference_token containing the literal index placeholder, first_reference_index, source_token and optional model instructions. Edit-instruction preparation preserves Main/Final. Canvas execution passes prompt unchanged without calling an LLM; Studio prepares it using its selected provider or direct mode. One connected collection/settings node is supported per workflow.
Item index always starts at 1. Qwen Edit reserves image_1 for Image Source: Item 1 goes to image_2. Qwen Create connects Item 1 to image_1. Match other models' conventions. Hover node titles, inputs and outputs for settings and wiring details.
Save the [PS] workflow and Refresh workflows. Changed contracts invalidate prepared edits; snapshots retain their settings. Legacy workflows remain supported. Setup backs up equivalent old bundles before upgrading.
