Open Details beside a LoRA (left of ×), an Image model selector, or Video's Workflow model details. Saved details appear immediately; refresh runs in the background. Click a trigger to copy it. Prompts, strengths and files stay unchanged.
LoRA Studio Safetensors headers supply offline triggers without hashing weights or a Civitai listing. Precedence: your edited list, embedded Studio usage phrases, Civitai, AI Toolkit legacy triggers. Phrases retain commas, spaces and case. Details shows public author/license/description, suggested strength (zero is valid), and training settings. Strength is not applied automatically. Planned steps differ from checkpoint progress; resolution is an area target and sample dimensions are defaults. Malformed/unsupported metadata is reported; older files retain legacy/Civitai support.
Edit trigger words opens a separate popup. Edit or Delete rows; Add trigger word reuses a blank row. Save omits blanks. Cancel/Close/Escape discards edits. Saved lists, including empty lists, survive refresh and feed the trigger picker.
Check again also checks Civitai. Only hashes/public IDs go online. Civitai site supports Automatic (.com + .red), .com, .green and .red; green uses .com's API. CIVITAI_API_KEY optionally supplies authentication. ↑ means a newer published version with the same base-model label, not guaranteed compatibility. Failed/unknown checks do not prove currency.
Startup and list refresh index all installed models into user-data/prompt_studio_model_metadata/library.sqlite3; saved headers/hashes are reused. Offline/deleted remote listings retain saved details; old JSON caches migrate. Header status dot > Background tasks shows progress, counts and errors without changing the connection-dot color.
Local deletion starts a grace period before cleanup; restoration cancels it. Maintenance requires ComfyUI running.
