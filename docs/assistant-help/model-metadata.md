Open Details beside a LoRA (left of ×), an Image model selector, or Video's Workflow model details. Saved triggers, notes and versions appear immediately; stale metadata refreshes in the background. Only hashes/public IDs go to Civitai. Click a trigger to copy it; prompts, strengths and files are unchanged.
Edit trigger words opens a separate popup. Add trigger word reuses an empty row; Save trigger words omits blank entries. Edit or Delete individual entries. Cancel, Close or Escape discards edits. Saved lists, even empty ones, survive Civitai refreshes and feed the trigger picker. Unmatched LoRAs can have custom triggers too.
↑ means a newer published version with the same base-model label. Review author instructions for compatibility. Unknown dates, missing matches or failed checks do not prove a model is current.
Civitai site supports Automatic (.com + .red), civitai.com, civitai.green and civitai.red. Green uses .com's API. Access depends on Civitai permissions; the server environment variable CIVITAI_API_KEY optionally supplies authentication.
ComfyUI builds user-data/prompt_studio_model_metadata/library.sqlite3 at startup for all installed LoRAs, diffusion models, checkpoints and reference adapters, regardless of workflow/browser. Saved hashes/details are reused; fresh entries skip the API. Refreshing model/LoRA lists rescans the library. Check again refreshes one file. Offline/deleted Civitai listings retain saved details; old JSON records migrate automatically.
Open the header status dot > Background tasks to monitor library progress, database counts and retry/errors in either studio. It updates while open; background activity never changes the ComfyUI/LLM status-dot color.
Local deletion starts a grace period when observed; metadata may be removed only afterward. Restoring the file cancels cleanup. Maintenance runs during Studio use, not while ComfyUI is stopped. Unmatched or altered files may have no accessible Civitai record.
