{"id":"xyz-plot","topic":"xyz-plot","studio":"image","summary":"Copy an entire XYZ plot into a new chat to adjust its axes and generation controls before rerunning."}
---
In an XYZ plot, Copy plot beside Open composite and Open plot data opens a new chat with the saved base prompt, workflow inputs, LLM mode, axes and generation controls ready to edit. Copying and reloading do not start generation or call the LLM. Adjust any details, then use the plot's Start button. The original plot stays intact; results and progress are not copied. The original creation workflow and axis targets must still be available.
