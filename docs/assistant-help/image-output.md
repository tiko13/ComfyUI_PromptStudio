In Image Studio, open the sidebar gear Settings and find Image output. In Video Studio, open Global settings and find Image output. These preferences are shared in this browser and apply to Save as WebP Conditional (Save_as_webp_cond) nodes on future submissions. They do not change video encoding or unrelated save nodes. Exact generation replays retain their saved output settings; plots retain the settings captured when prepared.
WebP is the default. Lossy mode exposes Quality; lossless mode exposes Compression effort. Encoding effort controls saving speed versus file size. PNG is always lossless and preserves incoming transparency; it exposes Compression level and Optimize PNG. Optimization overrides compression level. Switching formats retains the other format's preferences. Neither format creates transparency in an opaque image.
Enable force on a save node to retain that node's settings instead of these preferences. Connected output controls remain workflow-controlled. Settings identifies selected workflows and nodes with force enabled. Bundled Qwen Edit, RGBA and Background Removal workflows force lossless PNG, avoiding another compression loss when their results are edited again. Other workflows follow global preferences unless forced. Edit-mask pixel preservation can still require lossless WebP.
Date subfolders, filename prefixes, numbering, temporary previews and embedded prompt/workflow metadata remain available in both formats. Drag the original saved file onto the ComfyUI canvas to recover its workflow.
