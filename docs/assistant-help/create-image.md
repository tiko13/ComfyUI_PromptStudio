To make an image, enter a scene description in the message box at the bottom of the chat, below the conversation. This is the composer, separate from the Main and Final prompt editors in Settings. Do not describe it as a field at the top.
Choose Create in the controls below the message box to create a new image. With LLM amplification enabled, typing a description makes the action button read Send. Send a direct creation request such as "Create an image of a red sports car on a neon-lit street." A question asking how to make an image receives advice rather than generating one.
Enable {auto_generate_label} below the message box to generate an image after the prompt is created or revised. If it is off, a description only updates the prompts; enable it and submit with the message box empty to generate from the current prompt. In direct prompt mode, type the image prompt and use the action button to generate without an LLM rewrite.
Current action button: {send_label}; LLM amplification enabled: {llm_amplification}; automatic generation enabled: {auto_generate}. The button text changes with mode, typed text and queue activity; do not invent a button called Generate. If no Create workflow is selected, open the sidebar header gear (Prompt Studio settings), then ComfyUI workflow templates, and choose a Create template. Style, Framing and Resolution are in the right sidebar controls; the bottom Settings button opens that sidebar, while its header gear opens application settings.
