Open `/PromptStudio` on the ComfyUI server; use `/PromptStudio?mode=video` for Video. Capitalization is ignored. On LAN, replace localhost with the server's private IP and keep its port. Existing LAN sign-in still applies. Original extension links remain supported.
LAN sign-in expires when ComfyUI restarts or the session times out. If a frozen tab shows LAN sign-in expired, use its Sign in link, authenticate in the new tab, then return to the original tab. It reconnects automatically and keeps its drafts.
On phones and tablets, Privacy guard covers the entire screen with a solid background while disconnected, including open previews. The frozen message and any Sign in link stay visible. Reconnection restores the interface and drafts automatically.
A restored tab shows a waiting screen while ComfyUI is stopped. Start ComfyUI normally; checks retry automatically, or use Try again. A connecting spinner waits for the prompt worker, queue, extensions and configuration; Video also checks its companion services. Refresh once while ComfyUI is running to receive this behavior. It requires restored page HTML; browser-owned connection error pages cannot show it.
Use Image/Video in the standalone header. Detection retries and updates open status dialogs. Install appears only when the server confirms Video is absent, never just on a timeout or error.
If installed but not loaded, enable the companion, restart ComfyUI after installation and inspect startup errors. Connecting means its interface has not attached. Temporarily unavailable means detection failed; check the connection. Image handoff needs an open Video project.
