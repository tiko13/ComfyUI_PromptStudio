First distinguish a multi-stage ComfyUI graph from several Studio actions. For one graph, connect stages by their typed outputs: for example Prompt Slot to text encoding, base sampler LATENT to a compatible refiner, then VAE Decode to one final image output. Insert decode/encode or resize operations where the next stage needs a different type or size; model and latent compatibility still matters. Canvas position and node titles do not determine execution order.
Studio injects the first executable Prompt Slot/Prompt Amplify in graph order, not one prompt per stage. Fan its output to encoders that share a prompt. For another stage's independent text, use its saved widget or expose that STRING with a separately titled Prompt Studio Input. Do not add extra Amplify nodes expecting Studio to inject them all: unselected ones retain normal canvas behavior. Use separate Input nodes for controls such as Base steps and Refiner denoise; multiple Prompt Studio Samplers expose explicit per-node plot targets. Subgraphs must still produce resolvable executable nodes.
Keep exactly one executable image-output node. Intermediate Save/Preview nodes can cause rejection even with saving disabled. Save the graph with a [PS] prefix and refresh workflows. Upscale nodes classify it as Upscale; otherwise Image Source classifies it as Edit; Reference Image alone does not. Create/Edit needs a compatible prompt node. An arbitrary graph is not accepted just because it is named [PS].
For separate operations, generate in Create, choose Edit this image on the desired result, then use Upscale on the result you want enlarged. Select the appropriate templates in Settings. These are separate user actions; do not promise an automatic Create/Edit/Upscale batch chain. Reroll and exact saved-input replay have different purposes; use history help for those details.
