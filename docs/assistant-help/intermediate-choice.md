Intermediate / Choice (PS_IntermediateChoice) takes IMAGE and optional LATENT. Set a message and 1–32 option labels, one per line. The canvas shows one IMAGE output per option; connect each to its continuation. Each stage ends at one Choice or final output. Start from Studio, not ComfyUI Queue; XYZ plots require generation-only workflows.
Save intermediate defaults on. It uses the same saver as Save as WebP Conditional: filename prefix, PNG/WebP, lossless/lossy, compression, PNG optimization and WebP effort. Studio Image output preferences apply unless force is enabled. History references the permanent saved file directly, without a duplicate temporary preview.
With Save intermediate off, the full-size preview is temporary. History retains a tiny thumbnail. When cache cleanup removes the original, Studio shows the thumbnail and an expiry explanation; old records without thumbnails show a placeholder. A connection failure is reported as unavailable, not expired. These thumbnails cannot restore full-resolution images.
The image has message/options at its lower right. Selecting an option runs its branch with captured settings; the worker is free while waiting. Stages accumulate in one history entry, with buttons only on the latest stage. Video Studio keeps stage images and final video in one generation.
Create/reroll/replay in the same chat/project, reload, closing the page or restarting ComfyUI discards pending choices. Saved images remain. CPU image/latent handoffs are temporary and bounded; history does not restore buttons. Replay starts at the first stage.
Image workflows need a Prompt Slot and final image output. Video needs one H3 Director and native SaveVideo per final branch. Choice previews decoded IMAGE frames and does not produce H3 motion-context extension files. PS_IntermediateSource is internal; do not add it manually.
