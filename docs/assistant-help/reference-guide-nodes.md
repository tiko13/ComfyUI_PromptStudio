Prompt Studio Structure Input (PS_StructureInput) returns guide IMAGE, strength, inpaint_image and inpaint_mask. Wire width/height from Prompt Slot. Studio supplies photo/prepared guide, crop, placement and edited pose metadata. Empty or zero-strength guides return None and zero. Photo extraction needs the matching extractor; prepared maps do not. For pose preservation, connect the original source and use Studio's reviewed mask or a manual edit_mask MASK. White regenerates; black preserves. Disabled preservation returns empty inpaint outputs.
Prompt Studio Apply Qwen Structure (PS_ApplyQwenStructure) takes MODEL, VAE, guide and strength and returns MODEL. Connect both inpaint outputs for native control plus inpainting. It loads the configured Qwen patch only for an active guide; otherwise MODEL passes unchanged. Other model families need their own compatible application node.
Prompt Studio Edit Mask (PS_EditMask) composites generated IMAGE over source IMAGE. Connect Structure Input's inpaint_mask to preserve unpainted source pixels with the same mask used by the model. Save losslessly for exact pixels. The mask record is source-validated by Structure Input. The older mask_json path still supports standalone output compositing; without either mask, generated passes unchanged. Keep one connected Structure Input and Edit Mask per workflow.
