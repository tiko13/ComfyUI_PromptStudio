Prompt Studio Estimate Pose Mask (PS_EstimatePoseMask) estimates a white-on-black edit mask from source_pose_json and target_pose_json containing OpenPose joints. It returns preview IMAGE and MASK. Source joints must describe the full original image, not a donor. Source dimensions set the mask canvas. Guide dimensions, fit/crop and targeting match the target pose's execution geometry; target joints already describe any extracted crop.
The estimate combines the original body and new body positions, filling the torso, expanding head/hair space, using rounded limb segments and padding hands/feet. Padding is a percentage of body scale. Edges are softened. More than one detected person requires explicit all_people=true; otherwise use a manual mask rather than guessing the recipient.
In Image Studio, Edit background mask queues source pose detection and this node when no matching saved mask exists. Review and paint corrections, then Apply mask. Re-estimating replaces current painting and can be undone. This estimates anatomy, not a segmented silhouette; check long hair, loose clothing, carried objects and shadows. The existing Structure Input/Apply Qwen Structure/Edit Mask nodes perform native inpainting and exact unpainted-pixel preservation after review. H3 Video workflows do not expose Qwen pose inpainting.
