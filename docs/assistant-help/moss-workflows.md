Settings > General > Run setup offers MOSS SFT Create, SFT Controlled, Kromoss DMD2 Create and Kromoss Realism Create. Setup verifies BF16 models, the Qwen3.5 9B encoder, shared Flux2 VAE and recipe adapters. Current native MOSS nodes are required; no quantized checkpoint is supplied.
Kromoss DMD2 uses DMD2 at 1, 8 steps, CFG 1, Euler/simple. Realism keeps Kromoss BF16 and adds older DMD at 0.5 plus Smartphone Snapshot Photo Reality v14 at 0.5, with 12 steps. It automatically prepends the photo trigger. Set Studio Resolution to 1.5 MP to match the guide. This dual-turbo combination is experimental; quality on Kromoss is unverified. Its negative prompt has no guidance effect at CFG 1. Keep required adapters out of the user LoRA stack.
SFT exposes optional Destripe: 0 off; author starting values are 1 at 768 and 1.5 at 1024. Destripe is not a Kromoss preset.
Open Additional Inputs > Layout and control maps. Add object, character or exact-text boxes; drag, resize or enter percentages. Reorder background first. Palette colors describe appearance. Apply saves per chat/workflow; Cancel discards. Undo, redo, reset and JSON import/export are available. Generation captures applied state. Preview a map behind boxes or create a flat region map.
Controlled accepts color and depth maps. Color uses region IDs, not desired object colors. Depth is grayscale, near white; invert if needed. Photo depth requires the optional setup extractor. Maps share alignment, strength and start/end interval. Match framing; start 0/end 0.5 for synthetic maps or end 1 for photographic depth are starting points.
The control adapter stays loaded at zero strength. Choose SFT Create for an unpatched baseline. Kromoss with control is not offered until render validation. Boxes guide placement; exact text/position are not guaranteed. These are Image workflows; Video can use generated images as references.
