Settings > General > Run setup offers MOSS SFT Create, SFT Controlled and SFT 8-step · Optional Refine. Setup verifies BF16 models, the Qwen3.5 9B encoder, shared Flux2 VAE and recipe adapters. Requires native MOSS nodes.
SFT 8-step uses SFT DMD v0.1 at 1, 8 steps, CFG 1, Euler/normal and shift 5. Refine optionally enlarges the image 1.5× and runs 4 steps at denoise 0.15. New generation discards the choice.
Standard SFT exposes optional Destripe: 0 off; author starting values are 1 at 768 and 1.5 at 1024.
Additional Inputs > Layout and control maps fits inside Studio. Add object/character/text boxes or Draw; Select moves them. Right-click overlaps to choose, or Alt+click to cycle; covered selections stay draggable. Resize with handles or percentages. List order is foreground first. Descriptions grow; Expand editor enlarges them. Delete removes selection outside text fields. Ctrl+D duplicates; arrows move (Shift: larger steps); Ctrl+Z/Ctrl+Shift+Z undo/redo. Segments/Properties toggle resizable panels; Zoom/Pan/Fit canvas adjust the view. Palette swatches describe appearance. Apply changes saves per chat/workflow; Cancel discards. More holds reset and JSON import/export. Generation uses applied state.
Control maps accepts color/depth uploads or a color map from layout; regenerate when warned. Preview maps behind boxes with adjustable opacity. Color identifies regions, not object colors. Depth is grayscale, near white; invert if needed. Photo depth needs the optional extractor. Maps share alignment, strength and start/end; match framing. Start 0/end 0.5 for synthetic maps or end 1 for photographic depth are starting points.
The control adapter stays loaded at zero strength. Choose SFT Create for an unpatched baseline. Boxes guide placement, without exact text/position guarantees. These are Image workflows; Video can use generated images as references.
