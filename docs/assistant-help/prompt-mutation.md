Open the sidebar header gear (Prompt Studio settings), then Prompt Mutation Configuration. Choose the category you want to manage. Each opens a self-contained pop-up with its own search, entry list and Add button. Use Edit or Delete on an entry; categories that support disabling also have an Enabled control.
Add and Edit open an editor inside that pop-up. Save writes the entry to local configuration; Cancel closes the editor without saving. Close returns to the same place in Settings. Escape closes the editor first, then the category pop-up. If saving fails, the editor keeps the draft and displays the error.
Forbidden words applies to both studios; other categories configure image rewriting. See Forbidden words help for matching, replacements and enforcement.
