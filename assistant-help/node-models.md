Prompt Studio Model Loader (KCPP_PromptStudioModelLoader) takes model_type and unet_name and outputs MODEL. Set Model Type to one top-level folder under a configured ComfyUI diffusion-model directory; matching ignores case and includes nested folders. Choose a compatible unet_name. Image Studio exposes that folder's models and injects the choice into the queued snapshot. This loads diffusion weights, not CLIP, VAE or the assistant LLM. Load those separately as required by the graph. INT8 weights are detected from their header and require the optional Load Diffusion Model INT8 (W8A8) loader; other weights use ComfyUI's standard UNETLoader.
Prompt Studio LoRA Loader (KCPP_PromptStudioLoraLoader) accepts MODEL model and lora_type and outputs MODEL model. Put it between the model loader and the sampler/model patch chain. LoRA Type names one top-level LoRA folder, case-insensitive, including nested files; filenames starting with underscore are hidden. Image Studio's LoRA section supplies an ordered stack with individual strengths. It modifies the model only, not CLIP. Use LoRAs compatible with the loaded diffusion model; a folder name does not prove compatibility.
lora_stack_json is an injected API detail, hidden on the canvas. Without a supplied stack the node passes the model through. LoRA Type also accepts * for all folders. Image Studio saves selections with generations. Video Studio reads Type from an empty shared loader downstream of the Director and fills its stack; the separate RefMod / RefLoRA loader has its own adapter_type. Bundled Video loaders use MiniMax3. Turbo remains controlled by the sampling profile.
