In Image Studio References > Targeting…, Resolve donor and recipient uses the reference instruction, source image and reference image. It matches visible attributes to detected people, then shows two proposed boxes. Use these selections applies them. If ambiguous, refine the instruction or select manually. It uses the configured vision LLM; ordinary Find people does not.
Find object takes a short name such as jacket or chair. An existing selection limits the search to that region. Choose a returned candidate to refine the rectangle. Install Object detection (Grounding DINO Tiny) through Settings > Setup; it uses the optional host Transformers runtime. This slower CPU analysis runs only on request. Detection scores do not establish identity or ownership.
On supported RGB Edit workflows, select Apply to source, then Create edit mask. It uses the installed SAM ViT-B model and optional Segment Anything runtime. Review the white area, then enable Preserve source pixels outside this mask. Changed source or selection requires a new mask. One enabled mask is supported. This is final compositing: tight masks can clip clothing or moved limbs and leave seams. Output keeps source dimensions; WebP uses lossless saving. References and ControlNet work without masks.
Reference Edit Mask Composite (KCPP_ReferenceRegionComposite) accepts generated IMAGE, source IMAGE, mask_ref STRING, source_ref STRING and source_digest STRING; returns IMAGE. Wire decoded RGB output and the original source into it, then IMAGE to the image saver. It checks source file identity and mask dimensions, resizes generated pixels to source size and retains source pixels where the mask is zero. Studio exposes this only for a single direct VAE Decode-to-image-output graph. Video keeps its own temporal workflow and does not receive this image-composite option.
