---
In Image Studio open the header gear, Prompt Mutation Configuration, then Forbidden words. Add a Forbidden phrase, choose Replacement mode (Verbatim or Guidance), and enter Replacement; Save persists it in local forbidden_words.json. Edit, Delete, Search and Enabled work like other categories.
Matching ignores case and respects word boundaries; longer overlapping phrases take priority. Verbatim hard-replaces matches with exact Replacement text, without LLM approval. Guidance tells the backend LLM how to rephrase; its text is never pasted as a literal replacement. Empty Replacement asks for natural alternative wording in either mode, including Verbatim; it never deletes matches. Existing filled replacements retain Verbatim behavior; existing empty ones use Guidance. Literal replacements containing enabled forbidden phrases are rejected; guidance can mention them.
Both studios enforce the rules. Full image rewrites retry violations up to twice, then fail without accepting the prompt. Manual image submissions and replays are checked too. Video Director receives the rules; its compiler checks structured output and manual overrides. Ask the Director to rephrase or edit the document if compilation is blocked. Required video syntax cannot be replaced. A conflict with locked content or restricted edit scope can block a change; adjust the rule or explicitly authorize the content change. Disabled entries have no effect.
