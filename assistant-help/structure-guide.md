In Image Studio, open References and expand a card. Use for chooses Reference, Structure guide (ControlNet), or both. Both reference instructions and structure guidance work in compatible Qwen 2.1 Create and Edit graphs. One guide can accompany ordinary references. Current workflow support: {structure_guide}; guide types: {guide_types}.
Choose the guide type and strength. More options selects photo extraction or a prepared map, and Fit (whole image) or Crop (fill canvas). Show guide queues the same extraction/framing used for generation. Edit can reuse its selected source. Changing workflows keeps saved guides, showing them inactive when unsupported. History retains submitted settings and the executable graph.
More options > Apply guide > Whole guide skips LLM matching for one structure-only reference, including prepared maps. Extra instructions, selections, masks or Always use deeper analysis override it. Auto retains subject analysis.
An active guide can specify an edit with empty composer text; zero strength is inactive. Optional instructions can name the person to change. Amplification inspects structure-only images as analysis context, not ordinary appearance references. Targeting… crops the reference before extraction and places the guide in a selected source region. See reference-targeting for selection and limitations. This does not apply an edit mask.
Settings > Run setup offers ControlNet and separate optional pose, depth and sketch extractors. Edges need no extra extractor. Setup verifies weights and uses ComfyUI Manager for missing preprocessor nodes; restart when requested. Turbo workflows use the v0.3 six-step adapter.
Qwen Structure Guide (ControlNet), class KCPP_QwenStructureGuide, accepts IMAGE, guide_type, input_mode, fit, width and height; returns IMAGE. Feed the map to ZImageFunControlnet with the Qwen union MODEL_PATCH and VAE, then MODEL to the sampler. Video uses separate workflows.
