Chats save automatically. Failed saves offer Retry save and Export unsaved draft (JSON). Keep the tab open until saved or exported. Retry loading history retains temporary local edits. Invalid responses never count as loaded history or a successful save.
For an older browser draft, View draft compares each changed field or message with current history. Apply saves that change into its original chat; Dismiss keeps the current version. Unsent messages return to the original composer without sending; restore a missing chat first. Dismiss on the notice discards the entire recovery draft. Viewing alone never dismisses it, even with no changes. Close retains unresolved items across reloads. Refresh differences if history changed. New drafts identify local edits; legacy drafts compare stored values. Export remains available if browser storage fails.
For a storage failure, View draft inspects the copy; Dismiss warning only hides the warning. The size cap is Prompt Studio’s, not the browser’s. Server saves can still succeed; recovery clears the warning.
Reload reconnects generations through ComfyUI queue/history without resubmitting. Unmatched preparations become Interrupted; check ComfyUI before generating again. Connection failures are retried.
From Image Info (i) or a chat/XYZ Plot image preview, Copy to new chat creates a separate Image chat with that image linked to its existing file and its saved Main/Final prompts, settings, references, workflow, model, LoRAs and seed (including XYZ axis values). The original stays intact; copy/reload never generates or rebuilds prompts. Generate reviews and reuses saved inputs. Editing prompts or controls returns to current settings; Reroll can rebuild Final in LLM mode. Copy is disabled without saved generation inputs. Use these prompts instead restores prompts into the current chat.
