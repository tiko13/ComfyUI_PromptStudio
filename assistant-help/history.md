Chats save automatically. Failed saves offer Retry save and Export unsaved draft (JSON); keep the tab open until saved or exported. Retry loading retains local edits. Invalid responses never count as loaded or saved history.
View draft compares an older browser draft with current history. Apply saves each change into its original chat; Dismiss keeps the current value. Unsent messages return without sending; restore a missing chat first. Dismiss on the notice discards the whole draft. Viewing never dismisses it, even with no differences; Close retains unresolved items across reloads. Refresh differences after changes. New drafts identify local edits; legacy drafts compare stored values. Export works when browser storage fails.
For storage failures, View draft inspects the copy; Dismiss warning only hides the warning. The size cap is Prompt Studio’s. Server saves can succeed; recovery clears the warning.
Reload reconnects generations through ComfyUI queue/history without resubmitting. Unmatched preparations become Interrupted; check ComfyUI before generating again. Connection failures are retried.
Compare saved inputs never edits the chat. Restore candidate inputs applies and saves; wait for confirmation before reloading. On failure, keep the tab open and Retry save. Restore never generates.
In Image Info (i) or chat/XYZ Plot previews, Copy to new chat links the image and its saved Main/Final, settings, references, workflow, model, LoRAs and seed (including XYZ values) to a new Image chat. The original stays intact; copy/reload never generates or rebuilds prompts. Generate reviews and reuses saved inputs. Prompt/control edits return to current settings; Reroll can rebuild Final in LLM mode. Copy requires saved generation inputs. Use these prompts restores prompts into the current chat.
