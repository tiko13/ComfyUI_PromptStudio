Prompt Studio Sampler (KCPP_PromptStudioSampler) behaves like ComfyUI's standard KSampler. Inputs: model, positive, negative, latent_image, seed, steps, cfg, sampler_name, scheduler and denoise. Output: LATENT samples. Wire a compatible model, encoded conditioning and latent; decode samples with the matching VAE before saving images. Increasing steps changes sampling iterations, not the number of workflow stages.
Image Studio discovers this explicit sampler contract for XY(Z) sampling axes; it does not guess arbitrary nodes from fields named seed or cfg. Multiple Prompt Studio Samplers are supported and plot axes identify the specific target. Give each a descriptive title, such as Base sampler or Refiner. To expose an ordinary configurable scalar in the sidebar, use Prompt Studio Input. Video Studio's native MiniMax sampler path is defined by its workflow; this node does not replace the Director or Turbo policy.
Save as WebP Conditional (Save_as_webp_cond) takes images, filename_prefix, mode (lossy/lossless), compression and save (yes/no). It returns the original IMAGE batch and reports image previews to ComfyUI. save=yes writes WebP files to output storage under the prefix and date folder; save=no writes temporary previews, not permanent output files. It stores prompt/workflow metadata. Both modes are still executable image outputs: setting save=no does not remove this node from Studio's one-image-output count. In a multi-stage graph, use intermediate image connections and keep only the intended final image-output node active.
