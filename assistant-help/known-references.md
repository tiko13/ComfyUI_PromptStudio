Open Settings > Prompt Mutation Configuration > Known references to add or edit a name and Definition. Names match case-insensitively; longer overlapping names take priority. Disabled entries are ignored.
Main Prompt keeps matched names. For Final Prompt, the LLM interprets their definitions and omits the names and aliases, even when repeated in a definition. Definitions can describe content, guide the LLM, or combine both. Preserve descriptive qualities, qualifiers and their strength in the same or closely equivalent wording. Apply instructions without copying meta-instructions into the prompt. Reference details are supplied intent, even with low embellishment. Explicit user revisions may override conflicting details. This is semantic LLM interpretation, not scripted substitution.
Names are lookup keys; their dictionary meaning does not define the subject. If a generated Final still contains a matched key, Prompt Studio requests an LLM correction while preserving expanded details. After two unsuccessful corrections it reports an error and keeps the existing prompt. A local edit that cannot remove a key within its authorized scope also keeps the existing prompt; rebuild Final from Main to resolve all references.
