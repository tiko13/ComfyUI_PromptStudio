KoboldCpp Prompt Slot (KCPP_PromptSlot) passes prompt through unchanged. slot_name names the slot; secondary_instructions is a separate unchanged string, useful for trigger words. Outputs in order: prompt, secondary_instructions, width, height. Connect prompt to the positive text encoder and width/height to compatible latent sizing inputs. The secondary string must be wired to be used; it is not automatically concatenated into prompt. Prompt Slot does not call an LLM.
KoboldCpp Prompt Amplify (KCPP_PromptAmplify) takes text, additional_instructions, model_profile, style_preset/style_modifier, framing_preset/framing_modifier, thinking_mode, embellishment_level and KoboldCpp request controls. It outputs amplified_text, secondary_instructions, width, height. secondary_instructions bypasses the LLM. aspect_ratio, megapixels and multiple calculate dimensions; merely connecting the text output does not resize a latent.
In normal ComfyUI queues Amplify calls its kobold_url. In Image Studio the selected prompt node becomes a Slot in the temporary queued snapshot, avoiding double amplification; Studio's selected LLM provider performs the rewrite. The saved graph retains Amplify. With several compatible prompt nodes, Studio injects only the first executable one in graph order; slot_name does not create independently editable Studio stages. Other connected Amplify nodes can still run their own calls.
Image Studio supplies Resolution values for Create and the source image's exact dimensions for Edit. Video Studio uses its Director document for the main video prompt; adding a Slot does not replace the Director contract.
