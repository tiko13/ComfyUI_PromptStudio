Open References, expand a reference, then Crop / mask…. For a single workflow input, use its Crop / mask… button. This edits the reference supplied to analysis and generation.
Drag a Crop rectangle or enter percentages. Hide brush paints over unwanted pixels; Restore brush brings them back. Hide all followed by Restore brush isolates a detail. A circular cursor shows the brush footprint; adjusting Brush size updates a centered circle and pixel diameter immediately. Undo and Reset changes are available. Keyboard: focus the preview, move with arrows, paint with Space or Enter; crop fields support numeric entry.
Use prepared reference saves a separate PNG and replaces the active reference. The original file stays unchanged; attach it again to start over after applying. Closing before applying discards the draft. Hidden pixels become neutral gray, not a model-specific attention mask. Cropping changes reference dimensions and framing; it can remove context useful for pose/depth extraction. Ordinary references and ControlNet both receive the prepared pixels. Existing donor rectangles are cleared to avoid applying an old crop twice; recipient selections remain.
The editor runs locally without detection, segmentation or an LLM, supporting images up to 32 megapixels and prepared uploads below 20 MB. It does not preserve pixels in the generated result; use an Edit mask for that on supported Image workflows. Video workflow reference inputs use the same preparation controls.
