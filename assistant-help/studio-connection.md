Use Image/Video in the standalone header. Detection retries automatically and updates an open status dialog. Install is offered only when the server confirms that Video Studio is absent. A timeout, connection error or server error does not prove it is missing.
If installed but not loaded, check that the companion is enabled. Restart ComfyUI after installing it; inspect startup errors if it still fails. Connecting means its interface has not attached yet. Temporarily unavailable means detection could not reach it; check the ComfyUI connection. Image handoff also needs an open Video project.
