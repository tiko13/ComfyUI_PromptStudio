Prompt Studio Image Source (KCPP_ChatImageInput) loads image_ref, a Studio file reference with filename, subfolder and type, and outputs IMAGE image and MASK mask. source_name labels the source. Connect image into the edit pipeline in place of Load Image. Image Studio injects the chosen chat image into the first executable source node. The mask is inverse alpha (transparent pixels masked), or zero for an opaque image; it is not an automatic subject segmentation. An empty or invalid source fails validation.
Prompt Studio Reference Image (KCPP_ChatImageReference) has the same inputs/outputs but allows empty image_ref, returning no image or mask. Connect only to a downstream input that supports absence, or supply a reference before queueing. Add one node per independently assigned image; a custom node title labels the control, with source_name as fallback. It works in Create, Edit, Upscale and Video workflows. A reference alone does not make an Image Studio workflow an Edit template. It does not automatically add model-specific grounding or replace Video Director media roles.
Prompt Studio Upscale (KCPP_PromptStudioUpscale) accepts image_ref and upscale_factor plus optional prompt and secondary_instructions. Outputs: image, width, height, upscale_factor, prompt, secondary_instructions. It loads the source and calculates target dimensions; downstream nodes do the actual upscaling. Connect image to the upscale pipeline, sizing outputs where required, and prompt to conditioning if used. Image Studio's Upscale action supplies the selected image and factor; Use prompt when upscaling controls prompt inclusion. Keep one final image output and save a [PS] workflow.
