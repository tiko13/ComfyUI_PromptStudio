Reference instructions apply to the active workflow: {workflow}, mode: {mode}. Current reference interface: {reference_mode}.
Create mode supports visual references for the text prompt: enable Use LLM amplification, use a vision-capable LLM, click the message box at the bottom of the chat and paste one image with Ctrl+V. A Pasted reference attachment appears below it. Describe what to borrow from the image and send the request. The LLM interprets the image to write the text prompt; the attachment is not a direct image input to the generation workflow. There is no Add Reference toolbar button for this attachment. Its remove button clears it.
Dropping one image into a chat with an existing prompt also attaches it for the next LLM request. Dropping into a completely empty new chat instead imports and captions the image to start that chat. A chat with discussion messages but no prompt does not accept drops; paste into the message box there. These actions require LLM amplification and vision support.
Workflow image inputs are separate: use the active workflow's reference control only when exposed. The edited source is separate from additional workflow references. An image attached in the separate assistant conversation is visual discussion context, not automatically applied to Main or wired into generation.
If reference_mode is unknown, explain that the current reference interface has not been supplied rather than guessing.
